# 추세추종 매매일지 (Android)

추세추종계산기 규칙으로 매일 투자비중 가이드와 매매성과를 보여주는 안드로이드 앱입니다.
모든 데이터는 기기 내부에만 저장됩니다.

## 계산 규칙
| 항목 | 기본값 | 계산 |
|---|---|---|
| 총 투자금 | 입력 | |
| 최대 손실율 | 2% | 총 투자금 대비 |
| 목표손익비 | 1:3 | |
| 종목당 최대 손실율 | 8% | 손절선 |
| 종목당 최소 수익율 | 24% | 목표손익비 × 종목당 최대 손실율 |
| 1종목당 최대 투입비중 | | 총 투자금 × 최대 손실율 ÷ 종목당 최대 손실율 |
| 종목수 | | 총 투자금 ÷ 1종목당 최대 투입비중 (예: 1억 ÷ 2,500만 = 4종목) |
| 유닛 | 총 5 = 시장 2 + 종목 3 | |
| 시장유닛 | 약세 0 / 보합 1 / 강세 2 | 매일 시장상황 입력 |
| 종목유닛 | 시작값 1 (설정 가능) | 오늘 화면에서 이전 수익율 선택: 목표 미달성 −1, 진행중 0, 목표달성 +1 (0~3) |
| 1유닛당 금액 | | 1종목당 최대 투입비중 ÷ 총 유닛수 |

오늘 종목당 투입금액 = (시장유닛 + 종목유닛) × 1유닛당 금액

## 화면
- **오늘**: 오늘 시장상황·종목유닛(이전 수익율) 선택, 보유/최대 종목수, 투자비중 가이드, 매수 수량 계산(손절가/목표가), 오늘·누적 매매성과, 종목유닛 변화
- **매매기록**: 매수/보유(현재가)/청산 기록, 손절·목표가 도달 알림
- **시장일지**: 날짜별 시장상황·이전 수익율·종목유닛·메모·실현손익
- **계산기**: 위 입력값 저장 및 계산 결과
